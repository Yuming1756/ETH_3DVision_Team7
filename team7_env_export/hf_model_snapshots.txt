## Recreating the same snapshots on a new machine

Recommended local cache layout:

ETH_3DVision_Team7/
└── external/
└── hf_cache/
└── hub/

Example setup:

cd ~/ETH_3DVision_Team7
mkdir -p external/hf_cache

export HF_HOME=$PWD/external/hf_cache
export HF_HUB_CACHE=$HF_HOME/hub

Example exact-snapshot download:

python - <<'PY'
from huggingface_hub import snapshot_download

snapshot_download(
repo_id="Qwen/Qwen3-VL-4B-Instruct",
revision="ebb281ec70b05090aa6165b016eac8ec08e71b17",
)

snapshot_download(
repo_id="depth-anything/DA3NESTED-GIANT-LARGE-1.1",
revision="b2359bdf726fb44ef62acca04d629dcf158053e7",
)
PY

## Notes

1. The cluster paths above are documentation only. They do not need to exist on
   a new machine.

2. The small file sizes sometimes shown for files inside HuggingFace snapshot
   folders may refer to symlinks. The actual model blobs are stored elsewhere
   inside the HuggingFace cache.

3. HuggingFace access tokens are not included in this repository.

4. To run offline after downloading the snapshots, set:

   export HF_HUB_OFFLINE=1
