Dynamic Functional 3D Scene Graph
DA3 / Qwen-VL Model Manifest

## Purpose

This file documents the external HuggingFace models used by the dynamic
functional 3D scene graph pipeline. The actual model weights are not included
in this repository.

## Main HuggingFace models

1. Qwen-VL model

   Model ID:
   Qwen/Qwen3-VL-4B-Instruct

   Purpose:
   Used as the vision-language model for interaction reasoning, functional
   element/object identification, functional relation prediction, object-state
   inference, and seed-frame/label reasoning.

   Notes:
   Some earlier experiments used Qwen/Qwen3-VL-8B-Instruct. The submitted
   portable setup uses Qwen/Qwen3-VL-4B-Instruct as the recommended model.

2. Depth Anything 3 model

   Model ID:
   depth-anything/DA3NESTED-GIANT-LARGE-1.1

   Purpose:
   Used for metric depth estimation when the DA3 depth path is enabled.

## Expected local cache layout

On a new machine, the recommended local cache location is:

ETH_3DVision_Team7/
└── external/
└── hf_cache/
└── hub/

Example setup:

cd ~/ETH_3DVision_Team7
mkdir -p external/hf_cache

export HF_HOME=$PWD/external/hf_cache
export HF_HUB_CACHE=$HF_HOME/hub

## Example download command

python - <<'PY'
from huggingface_hub import snapshot_download

models = [
"Qwen/Qwen3-VL-4B-Instruct",
"depth-anything/DA3NESTED-GIANT-LARGE-1.1",
]

for model_id in models:
print(f"Downloading {model_id} ...")
path = snapshot_download(repo_id=model_id)
print(f"{model_id} -> {path}")
PY

## Exact cluster snapshots

The exact HuggingFace snapshot hashes used on the ETH cluster are recorded in:

hf_model_snapshots.txt

These snapshot hashes can be used for stricter reproduction.

## Offline/cache-only use

After the models have been downloaded or copied into the local HuggingFace
cache, the pipeline can be run in offline mode by setting:

export HF_HOME=$PWD/external/hf_cache
export HF_HUB_CACHE=$HF_HOME/hub
export HF_HUB_OFFLINE=1

## Repository policy

The following files are intentionally not committed to GitHub:

* HuggingFace model weights
* HuggingFace cache folders
* .safetensors / .bin model files
* HuggingFace access tokens

Only this manifest and the snapshot metadata are committed.
