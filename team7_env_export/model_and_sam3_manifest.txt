Dynamic Functional 3D Scene Graph
External Source / Checkpoint Manifest

## Purpose

This file documents external source folders and checkpoint files that were used
in the ETH cluster environment but are not included in the GitHub repository.

These files must be restored separately on a new machine if the corresponding
pipeline components are used.

## Recommended local layout

ETH_3DVision_Team7/
├── final_project/
├── team7_env_export/
└── external/
├── src/
│   └── sam3/
└── checkpoints/
├── cotracker3/
└── GroundingDINO/
└── weights/

## SAM3 source

Cluster source folder:
/work/courses/3dv/team7/sam3

Recommended local location:
external/src/sam3/

Restore example:

cd ~/ETH_3DVision_Team7
mkdir -p external/src

rsync -av --progress 
yuchen2@student-cluster2:/work/courses/3dv/team7/sam3/ 
external/src/sam3/

Install example:

conda activate team7_3dv
pip install -e external/src/sam3

Notes:
SAM3 was installed as a local editable source package in the original cluster
environment. It is therefore not fully restored by the portable requirements
file alone.

## Other local editable packages

The original cluster environment also contained editable installs for local
source packages such as SAM3, GroundingDINO, and Recognize Anything / RAM.
These are recorded in the exact environment files, but their source trees are
not included in this repository.

If a specific run requires one of these packages, restore the corresponding
source folder separately and install it with:

pip install -e external/src/<package_name>

## Repository policy

Do not commit the following files to GitHub:

* external/
* model checkpoints
* .pth / .pt / .ckpt / .safetensors / .bin files
* local editable source trees
* raw datasets
* previous output runs

These files should remain local and are documented here for reproducibility.
